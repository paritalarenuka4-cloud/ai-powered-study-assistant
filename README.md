# AI-Powered Study Assistant

An AI-powered study assistant web application built with React and Vite.

## Current Features

- Dashboard
- Sidebar navigation
- AI Chat interface
- Study Materials page
- Quiz page
- Progress page
- Settings page
- React Router navigation
- Study material search

## Technologies

- React
- Vite
- JavaScript
- CSS
- React Router
